# 交付说明

本包是「文件加密与权限隔离」课题的完整交付，包含两个可对比运行的 HTTP Web 服务版本。

## 包内清单

| 内容 | 位置 |
| --- | --- |
| V1 对照版（服务端持钥，可解密） | `v1_server_key/` |
| V2 目标版（搭建者无法解密 · 零知识） | `v2_zero_knowledge/` |
| 测试素材（md / py / js / docx / xlsx / pdf / mp3 / mp4） | `test_files/` |
| 素材再生成脚本 | `tools/make_test_files.py` |
| 端到端自动化测试（V1 共 9 项，V2 共 10 项，全部通过） | `tests/` |
| 技术说明（威胁模型 / 算法 / 自证机制 / 边界） | `docs/技术说明.md` |
| 现场演示脚本（10 分钟流程 + 应答） | `docs/演示脚本.md` |
| 运行截图 | `docs/screenshots/` |

## 三步跑起来

```
1) cd v1_server_key  && run_v1.bat   → http://127.0.0.1:8001
   （Linux/macOS：bash run_v1.sh）
2) cd v2_zero_knowledge && run_v2.bat → http://127.0.0.1:8002
   （Linux/macOS：bash run_v2.sh）
3) 浏览器打开任一地址，账号见 README（小孔只能加密，小张可解密）
```

## 快速验证"搭建者无法解密"

1. 打开 V2，用小张登录 → 生成密钥对（私钥包下载到本机）；
2. 用小孔上传任意文件；
3. 换回小张，解锁私钥 →「本地解密」→ 文件原样还原；
4. 点「服务器自证：它解不开」→ 服务端返回 **501 NO_PRIVATE_KEY**；
   「查看数据库表结构」→ 没有任何机密字段；
5. 对照 V1 的「服务端密钥库」：密钥明文躺在数据库里——这正是 V1 与 V2 的本质差别。

## 复跑自动化测试

```
python tests/e2e_v1.py    # 需要 V1 服务运行中
node tests/e2e_v2.mjs     # 需要 V2 服务运行中（Node 18+）
```
